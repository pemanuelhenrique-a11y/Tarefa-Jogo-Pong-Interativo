# Pong-Interativo

Recriação do clássico e antigo jogo **Pong**, sendo desenvolvido como um trabalho da disciplina de programação estruturada

### Demonstrações


### Controles
Como inovação, esse jogo contém controles um pouco diferentes, agora você pode joga Pong se movimentando para as 4 direções.
* 1° Player: W - cima; S - baixo; A - esquerda, D - direita;
* 2° Player: setas: cima, baixo, esquerda, direita;
* Pausar: aperte p;
* selecionar dificuldade: 1 - fácil, 2 - normal, 3 - difícil;

### Inovações
* Cores;
* As raquetes se movem nas 4 direções, para uma simulação mais realista do ping pong em um ambiente 2D e simplificado;
* Níveis de dificuldade, quanto maior o nível, maior a velocidade da bola;
* Modo 2 jogadores;
